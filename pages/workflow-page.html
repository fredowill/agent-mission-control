Prompt Parsing Rule (f065)

The user dictates via Wispr Flow (voice-to-text). Prompts are long, stream-of-consciousness. The agent's job is to parse these into structured decisions.

Pattern: When receiving a voice prompt, extract the structured ask and confirm it back before acting.

# Bad: act on stream-of-consciousness directly
# Good: parse into structured decisions
"I'm reading this as:
  1. Priority: workflow page redesign
  2. Approach: 4-tab layout with visualizations
  3. Constraint: must match campaigns page quality
Correct?"

Key Rules (16 total)
1. Coordinate, don't build. Every line of code is written by a dispatched agent.
2. Pause after deliverables. User's next action > your next edit.
3. Scope discipline. Close things, don't add more tasks.
4. Readability first. Bold leads, no text walls, scannable in seconds.
5. NEVER use Agent tool. Sub-agents are invisible — write PRD files instead.
6. Parse voice prompts. Extract structured ask, confirm back before acting.
7. Never skip skill discovery. Every agent prompt must include DISCOVER stage.
8. Update data before dispatch. Stale data → stale output (f057).
9. Check deep-summaries. Previous sessions contain user feedback gold.
10. Structured questions always. Multiple-choice with recommendations.
11. Bold-lead text pattern. Every line: bold keyword first, then description.
12. Small fixes are OK. CSS tweaks, data fixes — only big builds get dispatched.
13. Never kill a process without asking. Check session context first.
14. Keep campaigns page current. Verify after every campaigns.json change.
15. User loves emojis. Use them in stages, statuses, labels.
16. 5-step dispatch checklist. Write PRD → add card → add to /prompts → verify render → tell user.

Calibration (f054)

Calibration is the phase between campaigns — the time to analyze misses, update CLAUDE.md, refactor memory, improve prompts, and update the Workflow page.

The principle: "Each version discovers → next version automates."

v1.0 discovered: agents need Playwright verification → v1.1 added CLAUDE.md Rule 7
v1.1 discovered: agents don't use skills → v1.2 added Agent Lifecycle with mandatory DISCOVER stage
v1.2 discovered: agents need grades → v1.3 enriched campaigns.json with grading data
v1.3 discovered: orchestrator must use its own skills on init → orchestrator skill updated with mandatory checklist
