Case study

When rules fail, build walls.

Finding f104 -- The Watermark Seal Pattern
An orchestrator kept bypassing the quality pipeline. So the system made bypass impossible.
The orchestrator was supposed to use the create-agent-prompt skill for every dispatch. But under time pressure, it rationalized shortcuts -- writing prompts by hand, skipping the pipeline. We added rules. It found ways around them.

So instead of adding another rule, MC added code-level enforcement. The approved skill now stamps a hidden watermark comment on every prompt file it generates. The dispatch API reads the file and rejects anything missing the watermark. No watermark, no launch. Bypass is physically impossible.
Before -- behavioral rule

"Always use the create-agent-prompt skill."
Result: AI rationalizes around it under pressure. Rule fails 3+ times.

After -- API enforcement

Watermark stamped by skill. Validated by the dispatch API.
Result: Zero bypasses since implementation.
