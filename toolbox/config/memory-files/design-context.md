# Design Context — Mission Control

> MC-specific design system. phredomade.com design lives in `docs/` not here.

## Design System
- **Light mode**: White bg (#fff), surface (#f4f4f5), separator (#e4e4e7)
- **Fonts**: Plus Jakarta Sans (headings 700-800), DM Sans (body 400-500), DM Mono (mono)
- **Colors**: Purple #8b5cf6, Blue #3b82f6, Green #22c55e, Amber #f59e0b, Rose #ef4444, Cyan #06b6d4
- **Cards**: 12px radius, 1px border, subtle shadow, hover lift
- **Nav**: Centered pill bar, active = white bg + shadow
- **Agent cards**: Color bar top, agent-colored name, status badge, focus text

## Principles
- Apple-inspired: clean, spacious, scannable
- Bold leads on every list item. No walls of text.
- No scroll prisons. Collapsible sections for long lists.
- Every UI element must justify its existence (f047).
- Readability is sacred (f044).
