Getting Started

Get Mission Control running in 5 minutes. No setup wizards, no config files, no nonsense.

Prerequisite: You need Claude Code installed and working. MC is a management layer that sits on top of Claude Code -- it watches your agent sessions and gives you visibility into what they're doing.
What is this?

Mission Control is air traffic control for your AI agents. It's a local dashboard that shows you every Claude Code session running on your machine -- what they're doing, what they've learned, what went wrong. You see everything without opening a single file.

It's also a learning system. Mistakes get captured as findings, findings become rules, rules get enforced by hooks. The same mistake never happens twice.

Install (3 steps)
Step 1
Clone the repo
git clone https://github.com/fredowill/agent-mission-control.git .claude/agent-hub

Clone it inside your project's .claude/ directory. That's where Claude Code looks for hooks and config.
Step 2
Start the server
node .claude/agent-hub/server.js

Opens on http://localhost:3033. That's it. No npm install, no build step, no dependencies beyond Node.js.
Step 3
Open Claude Code in another terminal
Start a Claude Code session in the same project directory. The hooks in .claude/settings.json will automatically report to Mission Control. Refresh the dashboard -- you should see your session appear as a card.
What to look at first
Dashboard
Live agent cards. See every running session, what it's doing, and its current state.
Dispatch
Your task board. Bugs, features, ideas -- everything you need to work on, prioritized.
Campaigns
Multi-agent sprints. Coordinate 3-5 agents working in parallel on a big goal.
3 things to try
1
Run two Claude Code sessions simultaneously. Open two terminals, start Claude Code in each, and watch the Dashboard show both as live cards. This is the basic superpower -- seeing all your agents at once.
2
End a session with /end-session. Type /end-session before closing a terminal. It writes a structured retrospective -- what was accomplished, decisions made, unfinished work. Check the Dashboard card for a Retrospective tab afterward.
3
Check the Findings page. Go to /findings to see lessons learned from past sessions. These are the compound interest of the system -- each one prevents a future mistake. Add your own as you discover patterns.
