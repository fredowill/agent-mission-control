Lessons Learned
What we took away from the first coordinated campaign.
Lesson 01
“Playwright test everything”
Broke the Dashboard 3 times during the sprint. Never tested with a screenshot. Visual verification is non-negotiable.
Lesson 02
“Pause after delivering”
The user needs to act before you move on. Shipping three things in a row overwhelms. Deliver, wait, iterate.
Lesson 03
“Never dump prompts inline”
Use /prompts, not terminal text. Pasting multi-line prompts into terminals caused the worst session waste of the sprint.
Lesson 04
“Setup checklist before agents”
20 minutes of setup prevents 2 hours of recovery. Pre-flight checks for every agent launch.
Lesson 05
“Research agents are highest-value”
Not every agent should write code. Compass and Analyst produced insights worth more than any single feature.
Lesson 06
“Data change ≠ UI change”
The user sees the screen, not the JSON. If data updated but the UI didn’t refresh, the user sees nothing.
